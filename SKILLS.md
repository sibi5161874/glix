# Skills & Multi-Step Workflows

Standard multi-step workflows for the platform:

- **`add-module`**: Scaffold Next.js frontend route, Fastify API controller, Zod schema, and Postgres RLS migration.
- **`add-role`**: Update RBAC permission matrix, Zod enum, and Postgres policy definitions.
- **`add-doc-type`**: Register new document category and configure expiry notification triggers.
- **`seed-tenant`**: Generate isolated test organization with sample employees, leaves, and documents.
- **`deploy`**: Execute CI pipeline, database migrations, and production verification.
